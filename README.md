# Dashboard de Alunos 🎓

Projeto desenvolvido em **JavaScript** com foco em estudos e prática de desenvolvimento web.  
O repositório contém algumas aulas e exercícios, mas o principal projeto é um **Dashboard de Alunos**, utilizado para gerenciamento e visualização de informações acadêmicas.

---

## 📚 Conteúdo do Repositório

- Aulas e exemplos em JavaScript
- Exercícios práticos
- Manipulação do DOM
- Consumo de APIs
- Projeto principal: **Dashboard de Alunos**

---

## 🚀 Projeto Principal — Dashboard de Alunos

O dashboard permite visualizar e gerenciar informações dos alunos de forma simples e organizada.

### Funcionalidades

- 📋 Listagem de alunos
- 🔍 Busca e filtros
- 📊 Exibição de notas e desempenho
- 👨‍🎓 Cadastro de alunos
- ✏️ Edição de informações
- 🗑️ Remoção de registros
- 📱 Interface responsiva

---

- CSS3
